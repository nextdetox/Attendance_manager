# 📅 출석 관리 (Attendance Manager)

수업별 출석/결석을 달력으로 관리하고, 학교 규정에 따른 **F 학점 위험(결석 1/3 초과)**을 자동으로 계산해주는 웹 앱입니다. Firebase Auth + Firestore를 이용해 어떤 기기에서 접속하든 같은 계정으로 로그인하면 데이터가 동기화됩니다.

별도의 빌드 과정 없이 `index.html` 파일 하나로 동작하는 단일 페이지 앱입니다.

## ✨ 주요 기능

- **이메일 회원가입 / 로그인** — Firebase Authentication 기반, 로그인 정보는 브라우저가 아닌 클라우드(Firestore)에 저장되어 여러 기기에서 동일하게 확인 가능
- **수업 등록** — 수업 이름, 요일(복수 선택 가능), 주당 시간을 입력하면 학기 시작일부터 총 주차만큼 자동으로 달력에 일정이 생성됨
- **달력 기반 출석 체크**
  - 날짜를 클릭하면 그 날 있는 모든 수업이 표시되고, 수업별로 출석/결석/부분결석(시간 단위)을 기록
  - "이 날 전체 출석 / 전체 결석" 버튼으로 하루치 일괄 처리 가능
  - 날짜를 이동해도 그 날짜의 실제 기록 상태(출석/결석/부분결석/미체크)가 정확히 반영됨
- **결석 한도 자동 계산 (F 학점 경고)**
  - 학교 규정(전체 수업시간의 1/3 결석 시 F)에 따라 수업마다 주당 시간 × 총 주차 ÷ 3으로 결석 한도를 자동 계산
    - 예: 주 3시간 수업 → 한도 15시간 / 주 2시간 수업 → 한도 10시간 / 주 1시간 수업 → 한도 5시간
  - 결석시간이 한도의 1/2를 넘으면 🟡 노랑, 2/3를 넘으면 🔴 빨강으로 신호등 표시, 한도를 넘으면 F 위험 경고 문구 표시
  - 통계에는 "결석시간 / F 한도시간"이 함께 표시되어 언제 F가 되는지 바로 확인 가능
- **대한민국 공휴일 표시** — 2026~2027년 법정 공휴일(대체공휴일 포함)을 달력에서 빨간 날로 확인 가능
- **일정 등록** — 특정 날짜에 시험 / 휴강 / 메모를 자유롭게 등록·삭제 가능 (수업이 없는 날에도 등록 가능)
- **수업별 결석 통계** — 수업별 결석시간/한도, 경고 상태를 한눈에 확인

## 📖 사용 방법

1. 이메일/비밀번호로 회원가입 후 로그인합니다.
2. "수업 등록" 탭에서 학기 시작일과 총 주차를 설정하고, 수업 이름·요일·주당 시간을 입력해 수업을 등록합니다.
3. 달력에서 원하는 날짜를 클릭하면 그 날의 수업 출석 여부를 체크하거나, 시험/휴강 등 일정을 등록할 수 있습니다.
4. 왼쪽 패널 하단의 "수업별 결석 현황"에서 각 수업의 결석시간과 F 위험도를 실시간으로 확인합니다.

## ⚠️ 참고 사항

- 공휴일 데이터는 정부 발표 및 언론 보도를 기준으로 정리한 것으로, 실제 학사일정 확정 전 재확인을 권장합니다.
- 이 프로젝트는 학습/개인용 목적의 도구이며, 학교의 공식 출결 시스템을 대체하지 않습니다.
